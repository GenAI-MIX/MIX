# 06 수정안 생성 · 시각화 (이미지 광고)

두 층으로 고친다.

- **① 내용** — 05 LLM 판정(`rag/outputs/{ad_id}__{model}.json`)에서 B(필수 내용)·D1(심사필)이 `위반/확인필요`면 표준 문구를 고지 문단에 **추가**, C(금지 표현)·E는 광고 문구 위치를 표시하고 **고칠 방향만 제안**
- **② 표시 방법** — 전처리 JSON(`data/processed/image/json`)의 측정값을 05 노트북과 **같은 기준**(A2·A3·A4)으로 보고, 미달인 광고만 **원본 디자인을 최대한 지키면서** 고침

- 기준을 이미 통과한 광고는 고치지 않는다 → **원본 유지**
- "무조건 크게, 흰 바탕에 검정 글씨"가 아니라 **기준을 살짝 넘길 만큼만**, 원본의 색·정렬·굵기·배경을 그대로 쓴다
- 고친 뒤 **전처리와 같은 계산식**(`image_prep/metrics.py`)으로 다시 재서 통과 여부를 확인한다

## 폴더 구성

```
remediation/

├─ rules/phrases.yaml ← ① 내용: 항목별 추가 문구(B·D1)와 표현 수정 방향(C·E) — 코드 수정 없이 편집
├─ remediate.py    ← 실행 진입점
├─ examples/judge_sample/ ← 05 결과 형식의 테스트용 샘플 (실제 판정 아님)
├─ report/
│  ├─ make_report.py        ← 결과 보고서 PDF 생성
│  └─ 06_수정안_결과보고.pdf ← 결과 보고서 (사례별 원본·후보안·통과/불가 이유)
└─ remedy/
   ├─ content.py   ← 05 판정 결과 읽기, 추가할 문구·표시할 표현 결정
   ├─ diagnose.py  ← A2·A3·A4 판정, 고칠 문단과 목표 크기 결정, 추가 문구를 붙일 문단 선택
   ├─ color.py     ← WCAG 명암비, LAB 변환, 색상 유지한 채 밝기만 옮기는 fit_ink
   ├─ render.py    ← 지우기·재조판·스크림, 규격 복원(B 배경 줄 회수 · C 비주얼 축소)
   ├─ measure.py   ← 전처리 측정 함수 재사용
   ├─ verify.py    ← 수정본 재측정·재판정
   └─ viz.py       ← 후보안 비교 패널
```

## ① 내용 수정 (05 LLM 판정 연동)

| 05 판정 항목 | 판정이 위반/확인필요일 때 |
|---|---|
| B1~B12 필수 내용, D1 심사필 | `rules/phrases.yaml`의 표준 문구를 **본 고지 문단(글자가 가장 많은 위험고지 문단) 끝에 추가**. 상품 유형(투자성·예금성·보장성·대출성)에 맞는 문구만. 이미 비슷한 문장이 있으면 넣지 않음 |
| 　추가 방식 | 크기를 키울 필요가 없으면 **원본은 그대로 두고 아래에 이어 씀**(글머리표·표 보존), 키워야 하면 ② 재조판과 함께 같은 폰트·색·정렬로 |
| 　고지 문단이 아예 없음 (A1) | 광고 맨 아래 배경을 이어 붙인 띠에 문구를 넣음 |
| 　【 】 자리 | 보수율·대출금리·심사필 번호처럼 광고마다 다른 값 → 수정안에 【 】로 표시, 담당자가 채움 |
| C1~C5 금지 표현, E1·E2 | 카피는 **자동으로 바꾸지 않음**. 05의 `ad_quote`가 있는 OCR 블록을 주황 상자로 표시하고 고칠 방향 제안 |

05 결과가 없으면(폴더 없음 또는 `--judge-dir none`) ② 표시 방법만 수정한다.

## 판정 기준 (05 노트북 `TH`와 같은 값)

| 항목 | 지표 (전처리 JSON `metrics`) | 기준 |
|---|---|---|
| A2 명암비 | `risk_contrast_min` | ≥ 3.0 |
| A3 글자 크기 | `mobile_feed.risk_median_pt` (폭 390pt 환산) | ≥ 5.9pt |
| A4 헤드라인 대비 | `risk_headline_ratio` | ≥ 0.075 |

## 수정 원칙: 광고 규격(가로×세로 px)은 절대 바꾸지 않는다

캔버스를 늘린 수정안은 실제 집행용으로 쓸 수 없으므로, 모든 후보안은 **원본과 같은 크기**다.
고지에 필요한 공간은 광고 안에서 확보하고, 여러 후보를 만들어 비교한다.

| 처리 | 언제 | 무엇을 |
|---|---|---|
| 원본 유지 | A2·A3·A4 모두 통과 | 아무것도 안 함 |
| 색만 | 명암비만 미달 | 원본 글자 픽셀의 밝기만 이동 (색상·폰트·안티앨리어싱 그대로) |
| 제자리 재조판 | 크기 미달, 자리 있음 | 같은 자리·정렬·글자색, 획 굵기가 가장 비슷한 Pretendard, 기준 × 1.06 크기 |

자리가 모자라면 아래 후보를 모두 만들고 각각 다시 잰다.

| 후보 | 공간 확보 방법 | 디자인에 주는 영향 |
|---|---|---|
| A안 | 고지 영역 안에서 줄 간격만 정리 (글자 높이의 1.25배까지) | 고지 영역만 바뀜 |
| B안 | A안 + 모자란 만큼 **평평한 배경 줄**(위아래와 거의 같은 줄: 여백·단색 면)을 여러 곳에서 조금씩 뺌 | 글자·인물·로고는 그대로, 여백만 약간 줄어듦 |
| C안 | A안 + 고지 위쪽 내용을 같은 비율로 살짝 축소 (90%까지). 바깥 여백·테두리는 세로로만 눌러 선이 끊기지 않게 | 비주얼이 조금 작아짐 |
| B+C안 | B·C 각각으로 안 될 때: 배경 줄을 뺄 수 있는 만큼 빼고 나머지만 축소 | 둘을 조금씩 |
| 디자이너 검토 | 모든 후보가 불가 | **디자이너 브리프**: 규격 유지 시 필요한 추가 공간(px·%)과 각 안이 안 된 이유 |

추천안은 통과한 후보 중 **덜 건드리는 순서**(A → B → C → B+C)로 고른다.
각 후보에는 원본과 달라진 면적, 글자 배율, 글자색 ΔE, 뺀 배경 줄 수, 비주얼 배율을 함께 표시한다.

로고(짧고 문단 안에서 혼자 큰 글자, 브랜드명)는 글자로 다시 쓰지 않는다.

## 실행

```bash
cd remediation
python remediate.py --ids P021,P003     # 지정 광고
python remediate.py --all               # 전체 + summary.csv
python remediate.py --ids P021,AD07,P046,AD03 --judge-dir examples/judge_sample --out ../data/processed/remediation/content_sample   # 샘플 05 결과로 ① 내용 수정 시험
python report/make_report.py            # 결과 보고서 PDF
```

필요 패키지: `numpy`, `pillow`, `pyyaml` (requirements.txt에 이미 있음). 폰트: Pretendard (`~/Library/Fonts`), 없으면 AppleSDGothicNeo.

## 출력 (`data/processed/remediation/`)

| 경로 | 내용 |
|---|---|
| `viz/{ad_id}.jpg` | 비교 패널: 원본 · A안 · B안 · C안 · (B+C안) · 추천안 확대 전/후 · ② 판정표 · ① 추가 문구/표현 제안. 상자 색: 빨강=고칠 곳, 초록=고친 곳, 파랑=추가 문구, 주황=표현 검토 |
| `fixed/{ad_id}.png` | 추천안 이미지 (원본과 같은 규격) |
| `fixed/{ad_id}_{A,B,C,D}.png` | 각 후보안 (D = B+C안) — 용량이 커서 git에는 올리지 않음, 실행하면 생성 |
| `content_sample/` | 샘플 05 판정으로 돌린 ① 내용 수정 결과 |
| `json/{ad_id}.json` | 결정, 추천안, 후보별 통과 여부·불가 이유·디자인 지표, 디자이너 브리프, 판정 전/후, `content_add`(추가 문구), `content_flag`(표현 검토) |
| `summary.csv` | 광고별 결정·추천안·통과한 후보·A2~A4 전/후·추가 항목·표현 검토 항목 |

결정 라벨: 원본 유지 · 수정안 · 수정안 + 표현 검토 · 표현 검토(표시는 통과, 카피만 검토) · 디자이너 검토 · 고지 없음

디자인 보존 지표: 글자색 변화 ΔE, 글자 크기 배율, 캔버스 변화(px·%), 손대지 않은 면적(%).

## 전체 결과 (이미지 126개, 규격 고정, ② 표시 방법만)

| 결정 | 개수 |
|---|---|
| 원본 유지 | 24 |
| 수정안 (규격 그대로, 재측정 통과) | 27 — 추천 A 1 · B 7 · C 12 · B+C 7 |
| 디자이너 검토 (브리프 제공) | 74 |
| 고지 없음 | 1 |

디자이너 검토가 많은 주된 이유는 **A3 기준(모바일 390pt 환산 5.9pt)**이다. 고지문이 긴 포스터는 이 크기로 키우면 원본 높이의 10~20%가 더 필요하다.
이 기준은 승인된 실제 광고의 약 80%도 미달로 잡는다.
인쇄물 기준(A4 9pt ≈ 이 환산으로 약 4.1pt)으로 바꿔 돌려보면 원본 유지 52 · 수정안 31 · 디자이너 검토 42로 달라진다. A3 보정은 05(RAG·판정)와 같이 정해야 한다.

## 한계

- OCR 텍스트를 그대로 다시 쓰므로 OCR 오타·띄어쓰기 누락이 수정안에 그대로 보인다 → 최종본은 원문 문구로 교체 필요
- ① 내용 수정은 05 결과 형식에 맞춰 만들었고 샘플 파일로만 시험함 — 실제 `rag/outputs/` 결과로 다시 확인 필요
- 표준 문구(`rules/phrases.yaml`)는 법 조문·관행 문구를 바탕으로 한 초안 → 준법 검토 후 확정
- 추가 문구의 굵기는 원본 획 밀도로 추정해서 가끔 원본보다 한 단계 굵게 나옴
- 영상 광고는 아직 미적용
