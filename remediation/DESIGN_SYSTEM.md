# 06 수정안 디자인 체계

목표: **원본 광고의 디자인 결을 지키면서, 샘플 광고 전부가 수정 완료까지 가도록** 상황별 디자인 방법을 체계화함.
"안 가림·빈 공간·그림자" 같은 단일 규칙이 아니라, ① 상황을 진단하고 ② 그 상황에 맞는 디자인 방법을 조합하고 ③ 여러 안을 만들어 평가하는 구조로 바꿈.

---

## 1. 원칙

| 원칙 | 뜻 |
|---|---|
| 결 유지 | 원본의 그리드·정렬·서체 굵기·자간·색 체계·컨테이너(띠/박스) 형태를 그대로 따름 |
| 규격 유지 | 집행 규격(인쇄 판형, 배너 px, 영상 길이·해상도)은 바꾸지 않음. 단, 세로로 길어지는 상세페이지처럼 높이가 원래 자유로운 매체는 예외 |
| 최소 개입 | 기준을 살짝 넘길 만큼만 고침. 바꾸는 범위는 고지 → 고지 컨테이너 → 주변 레이아웃 순으로 넓힘 |
| 주요 요소 보호 | 헤드라인·인물 얼굴·로고·상품명·핵심 수치는 가리거나 줄이지 않음 |
| 완료 우선 | 한 가지 방법이 안 되면 다음 방법을 조합해서라도 수정 완료까지 감. 디자이너 검토는 마지막 예외 |

---

## 2. 상황 진단 (5개 축)

샘플 이미지 126개의 고지 영역을 모두 눈으로 확인해서 정리함.

### 축 A. 매체·규격

| 유형 | 규격 성격 | 샘플 예 |
|---|---|---|
| 인쇄 포스터 (A4·A3·B4 등) | 판형 고정, 실제 mm 크기로 판단 | P0xx 대부분 |
| 디지털 포스터·SNS 피드 | px 비율 고정, 모바일 표시 크기로 판단 | AD34~AD50 |
| 가로 배너 | px 고정, 높이가 매우 낮음 | AD02, AD04, AD06, AD08, P030, P018 |
| 상세페이지 (긴 세로) | **폭만 고정, 높이 자유** | AD03, AD05, AD07, AD09 |
| 영상 | 길이·해상도 고정 | V101~V180 |

### 축 B. 고지 컨테이너 (고지가 어디에 담겨 있는가)

| 유형 | 모습 | 샘플 예 |
|---|---|---|
| B1 브랜드 푸터 패널 | 하단 전폭 띠, 로고·QR·연락처와 함께 | 미래에셋 AD34~AD50·P077~P079·P087·P094 (흰 푸터+우측 로고), 하나 P021·P025~P029·P032·P033·P076 (초록 띠+좌측 로고), 우리 P011·P014~P016·P050 (짙은 띠+QR) |
| B2 박스·카드 안 | 둥근 박스·테두리 패널 안 | P036, P039, P042~P045, P047, P048, P081~P083, P086, P099 |
| B3 사진 위에 직접 | 사진 하단에 글자만 얹힘 | P004, P012, P013, P015, P051, P058, P060, P064, P070, P084, P085, P089~P091 |
| B4 문서형 본문 | 흰 배경 위 '유의사항' 목록 | AD01, AD03, AD05, AD07, AD09, P066 |
| B5 표·조건 블록과 섞임 | 혜택 표·조건 박스 사이사이에 고지 | P001, P002, P008, P023, P024, P026, P034, P062, P069, P074, P075 |
| B6 흩어진 각주 | ※ 각주가 여러 곳에 분산 | P067, P069, P100, AD07 |

### 축 C. 배경

C1 단색 · C2 그라데이션 · C3 사진·질감 · C4 일러스트·패턴

### 축 D. 주변 여유

D1 컨테이너 안에 여백 있음 · D2 컨테이너는 꽉 찼지만 위쪽 레이아웃에 여백 있음 · D3 위쪽도 꽉 참(사진 풀블리드 등)

### 축 E. 고지 구조

E1 한 문단 · E2 다단(2~3단) · E3 목록형(※·• 글머리) · E4 위계 있음(고지 본문 + 심의필·연락처 줄)

## 3. 디자인 방법 (8가지 도구)

| # | 방법 | 하는 일 | 지켜야 할 것 |
|---|---|---|---|
| M1 | 타이포 미세조정 | 자간 -2~0%, 행간 1.25~1.6배, 굵기 한 단계 이내, 단 폭을 컨테이너 폭까지 | 원본 서체 계열·정렬 유지 |
| M2 | 컨테이너 안 재배치 | 단 수 변경(1단↔2·3단), 로고·QR·연락처를 컨테이너 안에서 옮겨 폭 확보 | 브랜드 로고 위치 규칙(좌/우) 유지 |
| M3 | 내용 위계 정리 | 위험고지 핵심 문장은 기준 크기, 심의필·유효기간·연락처는 별도 줄로 정리. 흩어진 각주는 하나의 고지 영역으로 모음 | 문구 삭제 없음 (OCR 원문 그대로) |
| M4 | 컨테이너 확장 | 푸터 띠·박스를 위로 키움 (띠 색·질감·모서리 그대로) | 위쪽 주요 요소와 겹치지 않음 |
| M5 | 위쪽 레이아웃 재분배 | 늘어난 만큼 위에서 확보: 여백 줄 회수 → 블록 단위 이동(카피 묶음을 위로) → 사진 하단 트리밍(풀블리드 사진) → 비주얼 축소(≥90%) | 얼굴·헤드라인·로고 보호, 테두리 유지 |
| M6 | 대비 처리 (배경별) | 단색: 글자색 명도만 이동 / 띠·박스: 글자색과 띠 색 중 덜 바뀌는 쪽의 명도 조정 / 사진: 사진 아래쪽을 원래 톤으로 부드럽게 가라앉히는 페이드 / 영상: **광고에 이미 쓰인 색(팔레트)** 중 읽히는 색으로 글자색 변경 → 안 되면 명도 조정 → 마지막에만 글자 바로 뒤 국소 톤다운 | 박스·띠를 새로 얹지 않음 (원래 있던 컨테이너만 조정) |
| M7 | 규격 대응 | 판형별 실제 글자 높이로 목표 크기 계산 (4장) | 판형 자체는 바꾸지 않음 |
| M8 | 높이 자유 매체 확장 | 상세페이지는 고지 영역 높이를 그냥 늘림 | 폭·좌우 여백 유지 |

## 4. 상황별 처방 순서

각 상황에서 위에서부터 조합해 기준을 넘기는 첫 조합들을 후보로 만듦 (보통 2~4안).

| 상황 | 처방 순서 |
|---|---|
| B1 브랜드 푸터 패널 | M1 → M2(로고·QR을 옆으로/단 나눔) → M4 띠 확장 + M5(여백 회수 → 카피 블록 이동 → 사진 하단 트리밍) |
| B2 박스·카드 | M1 → M2 → M4 박스 확장 + M5 / 대비는 박스 채움색 조정(M6) |
| B3 사진 위 직접 | M1 → 사진 하단 페이드(M6)로 가독성 확보 → 필요하면 고지 영역을 위로 키우고 사진 하단 트리밍(M5) |
| B4 문서형 본문 | 상세페이지면 M8로 바로 해결 / 고정 규격이면 M1 → M3 → M5 |
| B5 표·조건과 섞임 | M3(고지를 표 아래 한 영역으로 모음) → M1 → M2(표 아래 2단) |
| B6 흩어진 각주 | M3로 하단 고지 영역에 통합(원래 위치엔 ※ 번호만 남김) → B1 처방 |
| 가로 배너 | M2(1줄 → 2단 배치, 좌측 로고 옆 공간 활용) → M4 하단 띠 확장 + 비주얼 크롭 |

## 5. 규격 프로필

같은 이미지라도 출력 판형에 따라 실제 글자 크기가 달라짐. 인쇄 기준 9pt(신문 전면 10pt)를 판형별 **필요 글자 높이**로 바꿔 판단함.

| 판형 | 폭 | 기준 | 필요 글자 높이 | 폭 2160px 원본에서 |
|---|---|---|---|---|
| B5 | 182mm | 9pt | 2.11mm | 25.1px |
| A4 | 210mm | 9pt | 2.11mm | 21.7px |
| B4 | 257mm | 9pt | 2.11mm | 17.7px |
| A3 | 297mm | 9pt | 2.11mm | 15.4px |
| 신문 전면 | 330mm | 10pt | 2.35mm | 15.4px |
| A2 | 420mm | 9pt | 2.11mm | 10.9px |
| 모바일 피드 (현재 05 기준) | 390pt | 5.9pt | — | 32.7px |

- 광고마다 출력 판형을 지정하고(메타 CSV에 열 추가), 없으면 매체 기본값 적용
- 보고서에는 판형별 통과 여부 표를 같이 보여줌 (예: "A3 출력 시 통과, A4 출력 시 1.4배 필요")

## 6. 영상 체계

| 유형 | 모습 | 처방 |
|---|---|---|
| V1 엔드 카드 정지 고지 | 마지막 정지 화면에 고지 | 이미지 B1/B2와 같은 방법 (원래 글자 지우고 같은 자리에 재조판) |
| V2 장면 위 하단 자막 | 움직이는 장면 아래쪽 | 원래 자막 스타일(외곽선·그림자 유무) 그대로, 장면마다 하단 안전 영역의 빈 곳 확인, 컷 경계에서만 위치 변경 |
| V3 노출 시간 부족 | 끝에 잠깐 | ① 엔드 카드 고정 시간을 늘리고 그만큼 직전 컷 끝을 다듬어 전체 길이 유지 ② 하단이 빈 장면에 같은 스타일 자막 추가 |
| V4 너무 빠름 (초당 글자 수) | 긴 고지를 짧게 | 고지를 2~3장 카드로 나눠 순서대로 표시 |
| V5 사진 위 대비 부족 | 밝은 장면 위 흰 글씨 | 방송 자막 방식: 얇은 외곽선/그림자, 또는 화면 하단을 부드럽게 가라앉히는 페이드 (박스 금지) |

## 7. 평가 (후보안 비교)

| 구분 | 항목 |
|---|---|
| 통과 조건 | A2·A3(판형 기준)·A4 / 영상 A2·A4·A5·A6·A7 재측정 통과 |
| 결 유지 점수 | 서체·정렬 일치, 글자색 ΔE, 컨테이너 형태 유지, 그리드 이탈 |
| 보호 점수 | 얼굴·헤드라인·로고·핵심 수치를 가렸거나 줄였는지 |
| 변경량 | 바뀐 면적, 움직인 요소 수, 비주얼 축소·트리밍 비율 |

통과한 안 중 결 유지 + 보호 점수가 가장 높은 안을 추천함.

### 확인된 한계
- 다시 쓰는 문구는 OCR 결과라 저해상도 영상(예: 640×480)에서는 오타가 그대로 나옴 → 원문 문구를 입력으로 받는 단계 필요
- 얼굴 위치를 따로 찾지 않음 → 글자 블록만 보호. 인물 위 배치 여부는 패널에서 확인 필요

## 9. 구현 순서 (원안)

1. 상황 자동 분류기 (축 A~E) — 샘플 전체에 붙이고 눈으로 확인한 분류와 맞춰 봄
2. 방법 M1~M8을 각각 독립 모듈로 (조합 가능하게)
3. 상황별 처방 순서표(4장)를 설정 파일로 — 코드 수정 없이 조정
4. 규격 프로필 + 판형별 판정
5. 영상 V1~V5
6. 평가·추천 + 보고서 (상황 유형별 대표 사례로 구성)
