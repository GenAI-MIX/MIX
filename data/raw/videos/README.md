# 04_영상광고 추가 80 (101~180)

금융 영상 광고 80개를 내려받아, 화면 위험고지가 **언제·얼마나 오래·몇 글자로** 나오는지 자동 분석한 데이터.
유튜브 링크 대신 **영상 파일(mp4)**을 넣어서 드라이브에서 바로 재생할 수 있다.

## 구성

| 항목 | 내용 |
|---|---|
| `영상/` | mp4 80개 (720p, H.264). 파일명 `번호_브랜드_유튜브ID.mp4` |
| `캡처/` | 고지가 가장 많이 보이는 순간의 원본 해상도 캡처 75장. 파일명 `번호_브랜드_ID_시점s.jpg` |
| `영상광고_추가80_위험고지구간.csv` | 영상별 분석 결과 (엑셀에서 바로 열림) |
| `캡처_한눈에보기.jpg` | 캡처 75장을 한 장에 모은 개요 이미지 |

- **매체**: TV CF 67 · 온라인 영상 13
- **위험고지**: 있음 75 · 화면 고지 없음 5 (브랜드 광고, 비교용)
- **브랜드**: 44개
  - 은행·인터넷은행
  - 카드
  - 생명·손해보험
  - 증권
  - 자산운용 ETF: ACE·HANARO·KODEX·KoAct·RISE·TIGER
  - 저축은행: SBI·웰컴·페퍼 (기존 데이터에 없던 업권)
- **분석 요약**: 고지 노출 합계 중앙값 7.0초, 초당 요구 글자 수 중앙값 32자

## 기존 데이터(1~100)와 겹치지 않게 한 방법

1. **같은 영상 제외**: 기존 CSV 2개의 유튜브 ID 100개를 제외했다.
2. **같은 광고의 다른 버전 제외**: 기존 영상 제목과 정규화한 제목이 같으면 제외했다(예: 같은 광고의 30A/30B ver.).
3. **화면이 같은 광고 제외**: 고지 화면 캡처가 기존 캡처나 이미 고른 영상과 거의 같으면(이미지 해시) 제외했다.
4. **눈으로 다시 확인해 제외**: 같은 상품·캠페인의 다른 편, 광고가 아닌 개인 채널 영상 8개를 직접 보고 뺐다.

## CSV 열 설명

기존 `영상광고_추가50_위험고지구간.csv`(51~100)와 같은 열에 4개를 더했다.

| 열 | 뜻 |
|---|---|
| 번호 | 101~180 (매체 → 브랜드 순) |
| 매체 / 브랜드 / 영상 제목 / 채널 / 길이(초) / 링크 | 유튜브 메타데이터. 브랜드는 업로드 채널 기준으로 확인 |
| 위험고지 노출 | 있음 / 화면 고지 없음 |
| 노출 구간(초) | 고지가 화면에 떠 있는 구간. 여러 번이면 `;`로 구분 (0.5초 단위) |
| **노출 합계(초)** | 구간 길이의 합 *(추가)* |
| 심의·심사필(OCR) | 캡처에서 읽은 심의번호. 못 읽으면 빈칸 |
| **고지 화면 글자 수** | 캡처 프레임의 글자 수 *(추가)* |
| **초당 요구 글자 수** | 고지 화면 글자 수 ÷ 가장 긴 노출 구간 *(추가)* — 클수록 읽기 어려움 |
| 캡처 파일 / 캡처 시점(초) | `캡처/` 폴더의 파일명과 시점 |
| **영상 파일** | `영상/` 폴더의 파일명 *(추가)* |

## 만든 방법 (자동)

1. 유튜브 공식 채널에서 금융사·업권별로 검색해 6~95초 광고 후보 948개를 모았다. 그중 120개를 고르고, 저축은행 등 9개를 더 내려받았다.
2. 1080p 이하로 내려받아 0.5초마다 프레임을 뽑고, 프레임 전체를 OCR했다(macOS Vision).
3. 고지 키워드(원금·손실·예금자보호·심의필·수수료·약관·금리 등)가 8자 이상 보이는 프레임을 "고지 노출"로 봤다. 연속 구간이 1초 이상이면 노출 구간으로 기록했다.
4. 가장 긴 노출 구간에서 글자가 가장 많은 프레임을 원본 해상도로 캡처했다. 그 캡처에서 심의번호를 다시 읽었다.
5. 드라이브 재생용으로 720p로 다시 인코딩했다.

## 주의

- **자동 분석이라 검수가 필요하다.**
  - 노출 구간은 0.5초 단위라 앞뒤로 0.5초쯤 차이가 날 수 있다.
  - 아주 작은 고지는 못 잡았을 수 있다.
  - 심의번호는 OCR 오타가 있을 수 있다(예: "심의펄" → 심의필). 48개만 읽혔다.
- **초당 요구 글자 수**는 캡처 프레임 전체 글자(로고·카피 포함) 기준이라 실제 고지 글자보다 조금 크다.
- **저작권**: 영상은 각 금융사의 저작물이다. 수업 프로젝트 분석용으로만 쓰고, 팀 외부 공유·재배포는 하지 않는다. 출처는 CSV의 링크를 참고한다.
